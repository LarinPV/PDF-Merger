# 📑 PDF Merger

> Быстрое и удобное объединение **PDF, Word (.docx, .doc), изображений (JPG, PNG, многостраничный TIFF, BMP, WEBP, GIF)** и текстовых файлов в единый PDF-документ прямо через контекстное меню Windows Проводника.

---

## ⚡ Ключевые возможности

1. **Интеграция в контекстное меню Windows Explorer в 1 клик**:
   - Выделите файлы в папке -> Правый клик -> **«Объединить в PDF...»**.
   - Или кликните правой кнопкой мыши по любой папке -> **«Объединить файлы в папке в PDF...»**.
   - При выборе нескольких файлов все они автоматически открываются **в одном общем окне**, а не в десятках отдельных окон (благодаря механизму Single-Instance IPC координации).
2. **0% фоновой нагрузки**:
   - Программа **НЕ висит в фоне**, не создает служб и не потребляет системные ресурсы (RAM / CPU) в режиме ожидания.
   - Запускается только при вызове, выполняет задачу и полностью выгружается из памяти.
3. **Бесшовный UX**:
   - После нажатия кнопки **«Объединить в один PDF»** программа формирует итоговый документ, открывает его в вашей программе просмотра (при включенной опции) и показывает всплывающий отчет.
   - Основное окно автоматически закрывается, не требуя повторных кликов на крестик.
4. **Сохранение оглавления и закладок (Bookmarks / Outlines)**:
   - Полностью переносит оригинальное дерево закладок из исходных PDF-файлов.
   - Автоматически создает разделы оглавления верхнего уровня по именам добавленных документов.
5. **Интерактивное изменение порядка (Drag & Drop)**:
   - Перетаскивание файлов в списке мышкой для быстрой сортировки.
   - Поддерживается перемещение как одного файла, так и **группы выделенных файлов**.
   - Кнопки **▲ Вверх** / **▼ Вниз** и горячие клавиши (`Alt+Up`, `Alt+Down`, `Delete`, `Ctrl+A`).
   - Перетаскивание новых файлов из Проводника прямо в окно программы.
6. **Высокое качество конвертации**:
   - **PDF**: сохранение векторной графики, разметки и закладок.
   - **Word (.docx, .doc)**: при наличии Microsoft Word или LibreOffice автоматически используется нативный движок (100% сохранение колонтитулов, шрифтов, таблиц, печатей и подписей). При их отсутствии работает встроенный конвертер с извлечением картинок и разметки.
   - **Изображения**: JPG, JPEG, PNG, BMP, TIFF (включая многостраничные сканы), GIF, WEBP (с автоповоротом по EXIF).
   - **Текст**: `.txt`, `.md`, `.rtf`, `.log` с поддержкой кодировок UTF-8 и CP1251.

## 🚀 Установка и запуск

### Способ 1: Готовый релиз (Без установки Python)
1. Скачайте архив релиза со страницы [Releases](https://github.com/LarinPV).
2. Распакуйте файлы в любую удобную папку.
3. Запустите **`install.bat`** (двойным кликом).
4. Готово! В контекстном меню Проводника появится пункт **«Объединить в PDF...»**.  
   *(Права администратора не требуются, запись производится в реестр текущего пользователя `HKCU`)*.

### Способ 2: Запуск из исходников
1. Клонируйте репозиторий:
   ```cmd
   git clone https://github.com/LarinPV/PDF-Merger.git
   cd PDF-Merger
   ```
2. Установите зависимости:
   ```cmd
   pip install -r requirements.txt
   ```
3. Запустите приложение:
   ```cmd
   python src/app.py
   ```
   *(Или запустите `run.bat` / `install.bat` для регистрации в меню)*.

## 🗑️ Удаление из контекстного меню

Чтобы убрать пункт из контекстного меню Windows:
* Запустите файл **`uninstall.bat`** (или нажмите кнопку **«Удалить из меню»** в правом верхнем углу интерфейса программы).

## 📂 Структура проекта

```
PDF-Merger/
├── assets/               # Иконки приложения (app_icon.ico, app_icon.png)
├── src/                  # Исходный код программы
│   ├── app.py            # Точка входа, обработка аргументов CLI и жизненный цикл
│   ├── gui.py            # Графический интерфейс на Tkinter (Drag & Drop, темы)
│   ├── merger.py         # Движок объединения PDF и переноса закладок
│   ├── converter.py      # Модуль конвертации Word, картинок и текста
│   ├── ipc.py            # Single-Instance координатор множественного выбора Explorer
│   └── registry.py       # Управление пунктами контекстного меню Windows в HKCU
├── tests/                # Модульные и интеграционные тесты
│   └── test_merger.py    # Тесты объединения, закладок, TIFF и конвертеров
├── install.bat           # Установка в контекстное меню в 1 клик
├── uninstall.bat         # Удаление из контекстного меню в 1 клик
├── run.bat               # Быстрый запуск программы
├── requirements.txt      # Список зависимостей Python
├── PDFMerger.spec        # Спецификация сборщика PyInstaller
├── LICENSE               # Лицензия MIT
└── README.md             # Документация проекта
```

## 🛠️ Сборка автономного `.exe`

Для самостоятельной компиляции автономного исполняемого файла с помощью PyInstaller:
```cmd
pip install -r requirements.txt
pyinstaller --noconfirm PDFMerger.spec
```
Итоговый файл `PDFMerger.exe` будет помещен в папку `dist/`.
